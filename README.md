# Klasifikasi Polaritas Berita Ekonomi Indonesia Terkait Kebijakan Pemerintah pada Detik

Oleh:
Faliqul Ishbah, Ganesha Mahardika Prasetya, Tiko Dava
Jurusan Informatika, Fakultas Teknik, Universitas Muhammadiyah Malang
Jl. Raya Tlogomas, Tegalgondo, Kec. Lowokwaru, Malang, Jawa Timur, Indonesia, 65144

Deskripsi Proyek

Proyek ini bertujuan untuk menganalisis polaritas sentimen berita ekonomi Indonesia yang berkaitan dengan kebijakan pemerintah menggunakan data dari Detik.com.
Penelitian ini membandingkan tiga pendekatan utama dalam Natural Language Processing (NLP), yaitu Pendekatan Klasik, Pendekatan Deep Learning, dan Pendekatan Transfer Learning, untuk menentukan metode terbaik dalam mengklasifikasikan sentimen berita menjadi positif, negatif, atau netral.
